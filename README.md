# Luggage storage occupancy in Italy

Live dashboard: https://giacbotta.github.io/occupancy/

How full the luggage storage competition is, city by city and hour by hour: Radical Storage, Bounce, Stow Your Bags.

- Rebuilt every hour from public sources.
- Only the page and its data live here. The scripts that collect the readings are private.
- One example of them, with a week of sample output: [stack/new-sites](https://github.com/Giacbotta/Giacbotta.github.io/tree/main/stack/new-sites).

Part of the [Nutrie log](https://giacbotta.github.io), post 11.
